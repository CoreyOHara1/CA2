# CA2: Analysis of Sligo Residential Property Sales

This repository contains the R scripts for the second assignment in my Data Science module, part of the Level 9 postgraduate programme in Big Data Analytics at Atlantic Technological University. The project uses Sligo residential property sales data from 2019–2025 to answer five research questions about recorded prices, sale dates and transaction characteristics.


## Project scope
- Inspecting and preparing the dataset carried forward from CA1
- Documenting missing values, reviewing exact copies and formatting variables
- Exploring the data using descriptive statistics and charts
- Defining null and alternative hypotheses and applying appropriate statistical tests
- Interpreting the findings and discussing the limitations of the analysis
